# Archive

Finished plans, spike reports, batch notes and test runs, kept as history. They are not kept up to date: what is still true has been folded into `docs/spec.md`, `docs/architecture.md`, the ADRs in `docs/decisions/` and `docs/plan/HANDOFF.md`, which win wherever they disagree with a file here.

Code comments and ADRs cite some of these files by name and section (for example `hot-join.md` §3 for carving, `setup-map-step.md` §5); that is why they stay in the repository.
