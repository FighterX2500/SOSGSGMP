# Songs of Syx events and which become global

Written 2026-11-01 from the game's data files (`data/assets/init/event`, V71). Each row is an event the game can start or chain to.

**Proposed:** G = fires on every player's city at the same step. W = world news: fires once for the world, every player gets the message, and its production change applies once. Blank = stays per city. A G event with a choice asks each player separately.
